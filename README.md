# cc-epub

Termux 端 EPUB 繁简转换 + 排版重置工具，专为港台竖排 EPUB 优化，完美兼容 Kindle KFX 格式。

## 功能特性

### 核心功能

1. **全量繁简转换**：覆盖正文、书名、作者名、目录标题、元数据描述等所有内容，使用 `tw2sp.json` 配置（含台湾短语/词汇转换）
2. **标点规范化**：直角引号「」→弯引号""、破折号统一为——、省略号统一为……、特殊逗号句号还原为标准全角标点
3. **竖排转横排**：自动修正 EPUB 阅读方向，重置 CSS 为横排布局
4. **首行缩进修复**：彻底解决"全角空格 + CSS 缩进"导致的 4em 叠加问题
5. **字体统一**：清除所有自定义字体嵌入和内联声明，统一调用 Kindle 自带默认字体
6. **字号统一**：清除所有自定义字号声明，统一为 `1em`，Kindle 中可自由调节
7. **KFX 兼容性**：过滤 Kindle 无法识别的复杂 CSS3 属性，避免转换后白页/卡死

### 繁转简覆盖范围

| 文件类型 | 处理内容 | 说明 |
|---------|---------|------|
| `.xhtml` / `.html` | 正文所有文本节点 | 批量合并调用 opencc，性能优化 |
| `.opf` | `<dc:title>` `<dc:creator>` `<dc:publisher>` `<dc:description>` | 书名、作者、出版社、简介 |
| `.ncx` | `<navLabel><text>` | EPUB 2.0 目录标题 |
| `nav.xhtml` | 导航页面中的目录文字 | EPUB 3.0 目录标题（作为HTML处理） |

### 标点转换对照表

| 港台原书 | 大陆规范 | 说明 |
|---------|---------|------|
| 「文字」 | "文字" | 直角双引号 → 弯双引号 |
| 『文字』 | '文字' | 直角单引号 → 弯单引号 |
| ﹐ | ， | 小逗号 → 标准全角逗号 |
| ﹒ | 。 | 小句号 → 标准全角句号 |
| — 或 ── | —— | 统一为双 em dash |
| … 或 ... | …… | 统一为双省略号字符 |
| ． | · | 全角句点 → 中间点 |
| ﹝﹞ ﹙﹚ | () | 特殊括号 → 标准括号 |

## 快速开始

### 一键部署

在 Termux 中运行以下命令，自动完成环境搭建、依赖安装和命令配置：

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/epubcc/cc-epub/main/install.sh)"
```

### 使用方式

```bash
# 单本转换
cc 书名.epub

# 批量转换
for f in ~/ebooks/*.epub; do cc "$f"; done
```

### 输出路径

转换后的文件自动保存至：`/storage/emulated/0/Download/E-book/书名-简中.epub`

## 注意事项

### 繁转简配置说明

- 默认使用 `tw2sp.json`（台湾繁体→简体，含短语转换），适合绝大多数港台书籍
- 如果是**香港繁体**书籍，可将 `cc.py` 中的 `tw2sp.json` 改为 `hk2sp.json`

### 依赖要求

- `opencc-tools`：Termux 原生繁转简工具
- `beautifulsoup4`：HTML 解析库
- `lxml`：XML 解析加速（可选）
- `git`：用于克隆和更新仓库

### 兼容性

- 支持标准 EPUB 2.0/3.0 格式
- 对 DRM 加密的 EPUB 无效
- 转换后通过 Send to Kindle 推送，自动转为 KFX 格式

## 故障排除

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 作者名/书名仍是繁体 | 旧版未处理 OPF 元数据 | 已修复，新版处理 `.opf` 中的 `<dc:*>` 标签 |
| 目录仍是繁体 | 旧版未处理 NCX 目录文件 | 已修复，新版处理 `.ncx` 中的 `<text>` 标签 |
| 部分台湾用语未转换 | 使用了 `t2s.json`（逐字模式） | 已改为 `tw2sp.json`（含短语转换） |
| 引号仍是直角「」 | 旧版未做标点规范化 | 已新增 `normalize_punctuation()` 函数 |
| 首行缩进 4em | 全角空格 + CSS 叠加 | 递归清理文本节点 + `!important` 覆盖 |
| 字体不统一 | 原书嵌入了自定义字体 | 清除 `@font-face` + 统一 `font-family: serif` |
| 字号不统一 | 原书对不同标签设置了不同字号 | 清除所有 `font-size` 声明 + 统一 `1em` |
| `command not found: cc` | 未重新加载 shell 配置 | 运行 `source ~/.bashrc` 或重启 Termux |

## 技术实现

### 处理流程

1. 解压 EPUB 到临时目录
2. 遍历所有文件，按类型分别处理：
   - **HTML/XHTML**：批量繁转简 → 标点规范化 → 清理空格 → 删除行内样式 → 注入覆盖 CSS
   - **CSS**：删除 `@font-face` → 清除冲突规则 → 追加覆盖规则
   - **OPF**：正则替换元数据中的中文内容（繁转简）→ 修正阅读方向
   - **NCX**：正则替换目录标题中的中文内容（繁转简）
3. 重新打包 EPUB（`mimetype` 无压缩且位于首位）

### 性能优化

- **批量繁转简**：将同一 HTML 文件中的所有文本节点合并后，一次性调用 `opencc`，避免逐节点创建子进程的开销
- **降级机制**：批量转换失败时自动降级为逐段处理，确保稳定性

### opencc 配置文件对照

| 配置文件 | 说明 | 适用场景 |
|---------|------|---------|
| `tw2sp.json` | 台湾繁体→简体（含短语） | **本脚本默认，最彻底** |
| `hk2sp.json` | 香港繁体→简体（含短语） | 香港书籍 |
| `t2s.json` | 繁体→简体（逐字） | 通用场景 |

## 核心问题解决对照表

| 痛点 | 解决方案 |
|------|----------|
| 4em 缩进 | 先清文本空格，再删行内样式，最后用 `!important` 覆盖 CSS |
| 字体不统一 | 删除所有 `@font-face` 和 `font-family` 声明，统一设置为 `serif`，所有标签继承 body 字体 |
| 字号不统一 | 清除所有 `font-size` 声明，统一为 `1em`，所有标签继承 body 字号 |
| KFX 白页 | 过滤不兼容的 CSS3 属性，统一 `line-height: 1.5` |
| 翻页方向错误 | 自动修正 OPF 中的 `page-progression-direction` |
| 标点不规范 | `normalize_punctuation()` 函数统一处理 8 种港台标点 |
